# AGUANTE — Descargas

Versión de escritorio de **AGUANTE**, el shooter de hinchadas del fútbol argentino.

## Cómo instalarlo

1. Entrá a la [última versión](https://github.com/hernanJardon/el-aguante-download/releases/latest).
2. Bajá **`AGUANTE-Setup-<versión>.exe`** y ejecutalo.
3. Windows puede mostrar un aviso de SmartScreen porque el instalador no está firmado:
   «Más información» → «Ejecutar de todas formas».

El juego se actualiza solo: cuando hay una versión nueva, avisa en el menú principal.

También hay una versión **portable** (`AGUANTE-<versión>-portable.exe`), que no se instala. Esa no
se actualiza sola: hay que bajar la nueva desde acá.

## Requisitos

Windows 10 u 11 de 64 bits y una placa de video con WebGL 2.
